# Tela de Login

Projeto simples de uma tela de login feito para praticar HTML5, CSS3 e JavaScript.

## O que foi usado

- HTML5 para criar a estrutura da página
- CSS3 para mudar cores, tamanhos e posicionamento
- JavaScript para verificar o login e mostrar ou esconder a senha

## Como abrir

Abra o arquivo `index.html` no navegador.

No VS Code, também é possível clicar com o botão direito em `index.html` e selecionar **Open with Live Server**, caso a extensão Live Server esteja instalada.
